4. BATCH THUMBNAILS (grid cards + batch detail page) — PARTIALLY DONE
--------------------------------------------------------------------------
Files:
  src/data/produceImages.js               (central photo registry)
  src/components/batches/BatchCard.jsx     (grid view thumbnail)
  src/pages/BatchDetails.jsx               (larger image on the detail page)

Real photos are wired in for produce types that have a matching entry in
src/data/produceImages.js — right now that's Mango, Tomato, Apple,
Green Apple, and Blueberry (src/assets/produce/*.png). Batches of those
types (e.g. MNG-102, MNG-118, TOM-054 in the mock data) show the real
photo automatically.

Batches whose produce type has no matching photo yet (Banana, Onion,
Papaya in the current mock data) still fall back to the old placeholder
box showing the imageKey text — search "PHOTO PLACEHOLDER: no photo
registered" to find that fallback.

To add a photo for another produce type:
  1. Drop the image in src/assets/produce/ (e.g. banana.png)
  2. Import it in src/data/produceImages.js and add it to PRODUCE_IMAGES,
     keyed by the exact produce name used in batch data (e.g. "Banana")
  3. Every thumbnail spot picks it up automatically — no component changes

Once the backend returns a real per-batch image URL instead of a static
produce-type photo, swap getProduceImage(batch.produce) for
batch.imageUrl in both files.
